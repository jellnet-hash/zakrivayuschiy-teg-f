# Закрывающий тег

Проектная работа Яндекс Практикума, посвящённая изучению продвинутой вёрстки, CSS-анимаций, SVG и работе с цветовыми темами. Проект представляет собой интерактивную страницу-рефлексию о прохождении курса и этапах обучения веб-разработке. 

## Возможности проекта

- Переключение между светлой, тёмной и автоматической темами.
- Анимированное меню выбора темы.
- Интерактивные карточки с изображениями.
- Уникальные CSS-фильтры для изображений.
- Анимация лайков и SVG-сердца.
- Модальное окно на основе элемента dialog.
- Адаптивная вёрстка для различных размеров экрана.
- Использование CSS-переменных для управления темами оформления.
- Применение вариативного шрифта Inter. 

## Технологии

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- SVG
- Flexbox
- CSS Grid
- CSS Custom Properties
- CSS Animations
- Dialog API
- Variable Fonts (Inter)

## Запуск проекта

1. Склонируйте репозиторий:

bash git clone https://github.com/USERNAME/zakrivayuschiy-teg.git 

2. Перейдите в папку проекта:

bash cd zakrivayuschiy-teg 

3. Откройте файл index.html в браузере

или запустите локальный сервер через расширение Live Server в VS Code.

## Что было реализовано

- Переключение тем оформления с сохранением выбора пользователя.
- Анимации элементов интерфейса через CSS Keyframes.
- SVG-анимация сердца с несколькими состояниями.
- Работа с пользовательскими CSS-переменными.
- Использование современных возможностей CSS: clamp(), mix-blend-mode, @supports, dialog, filter.
- Адаптивный интерфейс без горизонтальной прокрутки.
